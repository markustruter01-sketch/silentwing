the runways sit in the same coordinate frame as the taxiways and live aircraft.

RISK CLASS

the app the Sydney runways line up with the taxiways and aircraft.

This is the only file you may change.

   Replace that whole block with:

// ── Runway source ─────────────────────────────────────────────────────────────
// Runway centrelines come from OpenStreetMap aeroway=runway, the SAME source as
// the taxiways below and as YBBN's runways. Fetched via Overpass and projected
// with the formula above. Short OSM way fragments at the northern ends of both
// parallels have been stitched onto their parent ways.
//
// This replaces an earlier hand-built set derived from two survey points plus an
// assumed bearing. That set placed the two parallel runways on the wrong sides of
// the field — the long 16R/34L was drawn east and the short 16L/34R west, roughly
// 1.1-1.3 km from their true positions. Its self-check only measured runway
// LENGTHS, which were computed from the same assumption, so it could not fail.
//
// Measured from the coordinates below:
//   16R/34L  3947.1 m  (published 3962,  -0.4%)   bearing 167.7 true
//   16L/34R  2391.0 m  (published 2438,  -1.9%)   bearing 167.8 true
//   07/25    2420.2 m  (published 2530,  -4.3%)   bearing  74.2 true
//   parallel spacing 1035.6 m  (published ~1037)
// Lengths run slightly short because OSM maps the paved surface rather than the
// declared distance. Do NOT extend these to match published figures by computing
// an endpoint — that is the error this replaces.
